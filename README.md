# midnox TV

Eigene Startseite (Launcher) für Fire TV im midnox.de-Design.

- App-Reihe mit Favoriten, „Alle Apps“, Einstellungsmenü am Fernseher
- Emby: Weiterschauen, „Neu in …“ je Bibliothek, Titelbild mit Infos, Detailseite mit Staffeln/Folgen, Direktsprung in die Emby-App
- Home Assistant: Temperaturen, BYD, nächster Dienst, Hinweise (Dienstversteigerung, Müll, Akku)
- Kino-Modus: dimmt das Wohnzimmerlicht automatisch bei Emby-Wiedergabe
- Saison- und Feiertagsthemen (Halloween, Einheit, Advent, Weihnachten, Silvester, Ostern …)
- Automatische Updates über `update.json` in diesem Repository

Bauen: `./build.sh` (Android SDK platform 28, build-tools 35). Der Signaturschlüssel ist nicht im Repository.
